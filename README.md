# Certification Practice Suite: Anthropic Claude Architect (CCAR-F & CCAR-P) + Microsoft AI-103

Live Web Application: **[https://exams.shishyan.in](https://exams.shishyan.in)**  
GitHub Pages Mirror: **[https://shishyan.github.io/Certifications/](https://shishyan.github.io/Certifications/)**

## Overview
A multi-track exam readiness simulator and interactive flashcard/practice suite supporting:

1. **Anthropic Claude Certified Architect (CCAR-F & CCAR-P — 531 Verified Questions + 50 Core Concept Cards)**:
   - **CCAR-F Final (81 Questions)**: Claude Certified Architect – Foundations (`Q1`–`Q81`)
   - **CCAR-P Core (330 Questions)**: Claude Certified Architect – Professional Core (`Q82`–`Q411`)
   - **CCAR-P New (120 Questions)**: Claude Certified Architect – Professional New (`Q412`–`Q531`)
   - Covers Solution Design & Problem Framing, Multi-Agent Orchestration & Subagents, MCP & Tool Search (`defer_loading`), Prompt Caching (`cache_control`), Extended/Adaptive Thinking, Contextual RAG, Statistical Evaluation & Calibration, Message Batches API, Claude Code (`CLAUDE.md`, Scopes, Hooks, Skills), and Responsible AI Governance.

2. **Microsoft Certified: AI-103 Foundry (160 Verified Questions + 50 Core Concept Cards)**:
   - **Set 1: Core Bank (`Q1`–`Q100`)**
   - **Set 2: Practice Test (`Q101`–`Q160`)**
   - Covers Microsoft Foundry Agents, RAG, Sora 2, Speech MCP, Document Intelligence, Content Understanding, and Content Safety.

### Key Features
- **Instant Track Switcher**: Switch between **Anthropic Claude Architect (531 Qs)** and **Microsoft AI-103 (160 Qs)** in the top header with isolated `localStorage` mastery progress per track.
- **6 Study & Assessment Modes**:
  1. **Readiness Dashboard**: Tracks mastered items, scaled score (`0–1000`), missed items, bookmarks, set breakdown cards, and domain competency bars.
  2. **Study & Practice Mode**: Instant validation, architectural rationale reveal, set/domain/format/status filters, right-click option strikeout, and question navigator grid.
  3. **Timed Proctored Mock Exam Simulator**: Configurable question pools and exam lengths (including official 63-question / 120-minute CCAR simulation with 720 passing score and 60-question AI-103 simulation with 700 passing score).
  4. **Spaced-Repetition Flashcards**: Interactive flip cards (`Spacebar` or click) with option previews and *Again / Needs Study* and *Got It / Mastered* ratings.
  5. **Core Concepts (50 Master Cards per Track)**: Study guide reference grid and interactive concept flip deck across 10 domain sets.
  6. **Question Bank Explorer**: Real-time full-text search across all questions, tags, options, and explanations.
