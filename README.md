# Microsoft Certified: AI-103 Certification Practice Suite

Live Web Application: **[https://exams.shishyan.in](https://exams.shishyan.in)**  
GitHub Pages Mirror: **[https://shishyan.github.io/Certifications/](https://shishyan.github.io/Certifications/)**

## Overview
A professional-grade Pearson VUE exam readiness simulator and interactive study suite for **AI-103: Microsoft Foundry (Agents, RAG, Content Understanding, Safety & Observability)**.

### Key Features
- **100 Verified Exam Questions (`Q1`–`Q100`)**: Complete with detailed architectural explanations and rationales.
- **5 Official Pearson VUE Question Formats**:
  - **Single-Choice MCQ** (70 questions) — with right-click option strikeout and keyboard shortcuts (`1`–`4`, `Enter`, `←`/`→`, `B`).
  - **Hot Area / Interactive Dropdowns** (16 questions)
  - **Drag & Drop Tool / Signal Matching** (8 questions)
  - **Code & YAML Completion** (4 questions)
  - **Multi-Select Checkboxes** (2 questions)
- **5 Study & Assessment Modes**:
  1. **Readiness Dashboard**: Tracks mastered items, scaled score (`0–1000`, passing threshold `700`), missed items, bookmarks, and domain competency bars.
  2. **Study & Practice Mode**: Instant validation, explanation reveal, domain/format/status filters, and a 100-question navigator grid.
  3. **Timed Proctored Mock Exam Simulator**: 25, 50, or 100-question timed simulations with *Mark for Review*, pre-submission Item Review Grid, and domain score reports.
  4. **Spaced-Repetition Flashcards**: 3D flip cards (`Spacebar` or click) with *Again / Needs Study* and *Got It / Mastered* ratings.
  5. **Question Bank Explorer**: Real-time full-text search across all 100 questions, options, and explanations.
